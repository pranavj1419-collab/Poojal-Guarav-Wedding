# Poojal & Guarav — Wedding Invitation

## Features
- Interactive opening invitation
- Original couple photographs in the requested sequence
- One single scratch-to-reveal date card: Sunday, 28th February 2027
- Countdown to 7:00 PM IST on 28 February 2027
- Venue: The Grand Kasturi Resort, Bhopal, with directions link
- Responsive floral burgundy, cream, blush, and gold styling

## Publish using GitHub Pages
1. Upload `index.html` and the complete `images` folder to the root of a public GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
